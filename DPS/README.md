# DPS

DPS is a data repo for the manuscript entitled "Detecting poliovirus sequences in the Sequence Read Archive database using bioinformatics tools". 

The Figures folder contains excel files of total non-deduplicated alignments made between the non-poliovirus genomes in the RefSeq database to the capsid region of poliovirus genome segments using BLASTn. Also included is an R file containing the figure-generation codes for Figures 1 and 2.
    
    The bac_sum_removal excel file shows the bacterial RefSeq entries removed from Figure 2 results due to contamination. The first tab gives submission information for each entry. The second tab shows the original blastn results when aligning non-poliovirus genomes to the capsid region of poliovirus genome segments. The third tab shows BLASTn results after aligning the bacterial entries to the nucleotide database from NCBI.
